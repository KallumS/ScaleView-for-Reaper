# Session logs

One file per working session, named for the day it was written. A log records
**what happened and what it cost** - the work, the bugs, the measurements, and
the mistakes that were worth the time they took.

It is deliberately not a changelog. `git log` already says what changed; a log
here says what was learned, what was tried and abandoned, and what the next
session should pick up. Decisions that constrain future work get their own
record in `../decisions/`.
